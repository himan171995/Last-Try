# Diabetes Q&A edit (Dr. Mohan Padole)

HyperFrames project for the 60 s vertical (1080x1920, 30 fps) diabetes video.
Everything in `index.html` is generated; edit the generators in `build/` and re-run them.

```bash
# needs source.mp4 here (gitignored: the repo is public)
python3 -I build/phrases.py source.mp4 /tmp/phrases.json   # speech map + per-phrase Whisper text (reference)
python3 build/edl.py                                       # cut list + word timing -> build/edit.json
python3 -I build/aroll.py source.mp4                       # reframed, graded, upscaled A-roll + cut dialogue
python3 -I ../tools/make_doc_score.py assets/audio/score.wav --seconds 60 --lift 8.93 --thin 53.03 --outro 57.07
build/fetch_assets.sh                                      # SFX (Pixabay licence) from the vendored skill
python3 build/compose.py                                   # graphics, captions, sfx cue list
npx hyperframes check
npx hyperframes render --quality delivery --fps 30 --video-frame-format png -o renders/picture.mp4
python3 -I build/mix.py renders/picture.mp4 renders/final.mp4  # voice clean-up, ducked score, SFX, -14 LUFS
```

| File | Role |
| --- | --- |
| `build/transcript.py` | The phrases kept from the source, in order, with source times and Hinglish text. Fix caption wording here. |
| `build/edl.py` | Tightens pauses, snaps every cut to whole frames, times words, writes `edit.json`. |
| `build/aroll.py` | Per-frame 9:16 reframing (two-shot, patient, doctor medium/close with slow push-ins), grade, denoise, Lanczos upscale, sharpen, vignette, grain. Shot changes sit on the removed pauses so jump cuts read as camera changes. |
| `build/compose.py` | Writes `index.html`: hook stat, title, lower third, Charaka Samhita card, anatomy/dairy/grain/kapha/sweets scenes, end card, captions; and `build/sfx.json`. |
| `build/mix.py` | Dialogue chain (HPF, denoise, EQ, de-ess, compression, loudnorm), score ducked by the voice, SFX, final -14 LUFS / -1.5 dBTP, mux. |
| `build/asr_spans.py` | Re-transcribes chosen spans with more context (used to check caption wording). |
